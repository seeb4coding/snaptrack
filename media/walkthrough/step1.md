SnapTrack saves a snapshot of your folder so you can always go back to this moment.

**How to start:**

Open the **Source Control** panel (`Ctrl+Shift+G`), then click the button below -- or use the **Start Tracking This Folder** button in the Source Control title bar.

[Start Tracking This Folder](command:snaptrack.init)

**What happens next?**

SnapTrack creates a hidden `.snaptrack` folder in your project and stores a first snapshot of every file. From now on, any file you edit, add or delete will appear in the **Changes** list.

No Git required. SnapTrack works in any folder.
